# FlowOS
FlowOS, Arch Linux tabanlı ve KDE Plasma masaüstü ortamını kullanan modern bir işletim sistemi projesidir. Özgün tasarımı, beyaz-pembe renk teması ve kendine ait marka kimliğiyle farklı bir Linux deneyimi sunmayı hedefler. Bu depo, FlowOS'un kaynak kodlarını, proje dosyalarını ve sürümlerini içerir.
